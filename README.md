# Chat Bot

A simple web-based chat box, built as a learning project for full-stack development.

## Goal

Build a chat bot UI where a user types a question, submits it, and gets an answer. All previous questions and answers stay visible on the same screen, like a normal chat window (the message area scrolls when they no longer fit).

Planned direction:

1. **Now:** the "answer" is just the question echoed back (no backend).
2. **Next:** replace the echo with a real backend (e.g. a Spring Boot service) that returns answers.
3. **Later:** publish the site publicly (static hosting such as GitHub Pages or Netlify), with the backend deployed separately.

## Tech stack

- **HTML** (`index.html`): page structure
- **CSS** (`style.css`): look and layout
- **TypeScript** (`script.ts`): chat logic, compiled to `script.js` (the file the browser actually runs)

## Project structure

| File | Purpose |
|---|---|
| `index.html` | The chat window; links to `style.css` and `script.js` |
| `style.css` | Chat bubbles, scrolling message area, form styling |
| `script.ts` | Source code. Edit this one |
| `script.js` | Generated by the compiler. Do not edit by hand |
| `tsconfig.json` | TypeScript compiler settings (strict mode, source maps on) |
| `.vscode/launch.json` | VSCode debug configuration (Chrome, port 8000) |

## Getting started

Requires Node.js and npm.

```
npm install
```

Run these in two terminals:

```
npm run watch                  # recompile script.ts on every save
python3 -m http.server 8000    # serve the folder
```

Then open http://localhost:8000.

Other commands: `npm run build` compiles once.

## Debugging

Press **F5** in VSCode and choose "Debug chat in Chrome" (the server must be running on port 8000). Breakpoints can be set directly in `script.ts`. You can also use Chrome DevTools (F12 → Sources).

## Notes

- Always edit `script.ts`, then recompile. Changes to `script.js` will be overwritten.
- Everything in this project is public once published, so never put secrets or API keys in the front-end files.
